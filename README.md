# HumStudio — hum-to-MIDI mini DAW
Hum or sing into your mic; YIN pitch detection maps your voice to notes on a virtual keyboard and records them into multi-track songs. Piano roll, drum machine, 12 instruments, per-track FX/mix, loop, metronome, key/scale snapping. Export mix/track WAV and song/track MIDI.
`npm i && npm run dev` · `npm test` · `npm run build`
